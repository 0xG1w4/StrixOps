# StrixOps v1.3.4

Release date: 2026-09-13.

The login card brings the StrixOps identity, landscape observatory artwork and
warm primary action into a consistent layout. Desktop keeps artwork on the left
and form on the right. Narrow screens stack them, while short landscape screens
keep the fields visible beside the image. Keyboard focus and reduced-motion
preferences are supported.

New passwords must contain 8–32 Unicode characters after NFKC normalization.
The frontend and backend apply the same length rule. Existing passwords remain
valid for login and current-password verification, including passwords longer
than the new maximum. Common-password checks, hashing and session protection
remain in place; no account reset or data migration is required.

## Upgrade

Once outstanding work has completed, update the checkout and run:

```bash
./strixops.sh install
./strixops.sh start
./strixops.sh status
```

Reload the browser after upgrading. The sandbox image remains
`strixops-sandbox:1.3.0`; no sandbox rebuild or proxy CA reimport is required.

See [account settings](authentication.md) and [artwork source](login-observatory.md).
