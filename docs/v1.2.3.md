# StrixOps v1.2.3

Release date: 2026-09-12.

Task and project report readers now show clearer heading and paragraph spacing,
bullet points, numbered lists and nested indentation. Long inline values can wrap
without changing their text. Wide tables and code blocks scroll within their own
regions; existing supported task flowcharts keep their separate scroll region.
The existing Mermaid syntax subset and project report rendering capabilities are
unchanged.

The shared `reporting/report_format` skill is automatically included for root and
child Agents and final report synthesis. It guides readable paragraphs, meaningful
headings, lists and tables while retaining the report's required content,
sections, severity, language, credential details and evidence requirements.

Synthesis and deterministic fallback reports also apply conservative paragraph
breaks at sentence boundaries in long plain prose. Literal code, tables and inline
syntax are preserved. Formatting adds no model calls and does not introduce new
task-failure conditions or change scan rules.

## Upgrade

Let active tasks finish before upgrading and keep existing persistent paths.

```bash
git fetch origin tag v1.2.3
git switch --detach refs/tags/v1.2.3
npm --prefix console/web ci
npm --prefix console/web run build
uv sync --frozen --no-dev
```

Restart Console after upgrading. Existing reports benefit from the display
improvements, but their stored Markdown and download contents are not rewritten.
Newly generated reports receive the formatting guidance and paragraph handling;
their downloads contain that formatted, stored Markdown.

No task-data migration, sandbox image rebuild or certificate reimport is required.
