# StrixOps v1.3.1

Release date: 2026-09-13.

The login page now starts with an empty, editable username and verifies the
credentials entered by the user. A single Login heading and essential form
controls replace introductory workspace copy. Original starfield artwork frames
the form on desktop and adapts to small screens.

The existing account, saved password, first-login password change, session
protection and login limits remain in effect. Existing scans, queued tasks and
MCP capture are independent of browser login and logout.

## Upgrade

Once outstanding work has completed, update the checkout and run:

```bash
./strixops.sh install
./strixops.sh start
./strixops.sh status
```

Reload the browser to load the new page. There is no password reset, database
migration, sandbox image rebuild or proxy CA change in this release. Public
frontend assets now participate in the manager's build fingerprint.

See [account settings](authentication.md) and [artwork source](login-artwork.md).
