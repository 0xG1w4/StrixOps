# StrixOps v1.2.1

Release date: 2026-09-12.

Task conversations now open on **all Agents**. Explicit links to root or a child
Agent retain that selection. All-Agent viewing continues to send new operator
hints only to root; choosing a specific Agent selects that hint recipient.

Conversation controls use a responsive grid based on the panel width. The
Agent selector stays within its available space even with long names. On narrow
screens it occupies a full row, above the Agent-panel and follow controls.
Transcript status no longer repeats a long selected Agent name. Keyboard focus,
Agent-panel dismissal and follow behavior remain available.

## Upgrade

```bash
git fetch origin tag v1.2.1
git switch --detach refs/tags/v1.2.1
npm --prefix console/web ci
npm --prefix console/web run build
uv sync --frozen --no-dev
```

Restart Console after current work completes, keeping existing persistent paths.
No task-data migration, sandbox image rebuild or certificate reimport is required.
