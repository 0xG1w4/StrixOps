# StrixOps v1.1.5

Release date: 2026-09-11.

This release improves optional Perplexity research for Web and Internal scans.
Search failure is isolated from scan execution, including when the service is
disabled, the key is missing or invalid, or the account has no credit.

## Changes

- Add shared Agent guidance for focused, current public research and for
  continuing with other tools when search is unavailable. Target findings still
  require actual evidence; search results do not expand the authorized scope.
- Add an enable switch, `sonar` / `sonar-reasoning-pro` selection, a configurable
  10–300-second timeout and a saved-settings connection test in Integrations.
- Preserve citations, reject incomplete or malformed answers, bound retries and
  share permanent-failure state across Agents within one run.
- Show search outcomes, timing and available provider-reported usage in task
  details. Unknown usage remains unknown; diagnostics contain no query contents.

Existing saved keys remain usable. The Console supplies configuration to new
engine processes automatically. MCP request tests retain their existing tools,
container isolation and time budgets. Historical prompt snapshots and scan data
are not rewritten.

## Upgrade

```bash
git fetch origin tag v1.1.5
git switch --detach refs/tags/v1.1.5
npm --prefix console/web ci
npm --prefix console/web run build
uv sync --frozen --no-dev
```

Restart Console with its existing persistent paths after current work completes.
Settings and prompt changes apply to newly started scans. No CA reimport or data
migration is needed. The connection test sends one public Perplexity query and
can consume API credit; development validation uses simulated provider replies.

## 中文重點
