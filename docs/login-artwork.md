# Login starfield artwork

This is the original v1.3.1 artwork. The current login page uses the
[observatory artwork introduced in v1.3.4](login-observatory.md).

The original starfield was generated for the StrixOps login page with the built-in
imagegen tool on 2026-09-13. It uses no reference artwork, stock photography or
third-party image service at runtime.

Project asset: `console/web/public/images/login-starfield.webp`.
The generated PNG was encoded as WebP at quality 88 without resizing or visual
editing: 1672 × 941 pixels, 230,352 bytes. The image is served locally alongside
the Console and remains decorative; all labels and controls are real HTML.

## Generation prompt

Use case: stylized-concept. Asset type: production background artwork for an elegant secure login page. Primary request: an original artistic starry night sky, quietly magnificent and immersive. Create a wide landscape 16:9 composition, high resolution. Rich deep midnight sky with countless fine naturally varied stars and a sweeping delicate Milky Way dust cloud diagonally through the left two thirds, luminous pearl and restrained warm silver highlights, soft blue-black depths. Painterly astronomical fine-art photography, subtle organic grain, nuanced atmospheric light, exceptional detail but calm contrast. The rightmost third must remain very dark, sparse and visually quiet for a readable login form to be composited in the website. The most beautiful galactic detail should sit around 30 percent from the left and 45 percent from the top, with dark falloff along edges. Full bleed sky only, no mountains, buildings, people, spacecraft, planets, horizon, interfaces, frames, icons, logos, letters, captions, typography or watermarks. Avoid saturated neon purple, loud lens flares and oversized stars. This is a finished standalone artwork, not a screenshot or UI mockup.
