# StrixOps v1.2.5

Release date: 2026-09-12.

Adds `strixops.sh` for Linux/macOS source checkouts: install, uninstall, start,
stop, restart, status and logs. The manager keeps frontend installation and
Python dependency sync together, verifies readiness/version, remembers absolute
data paths and avoids duplicate Console processes. Maintenance checks outstanding
scan, queue, MCP and FOFA work; uninstall retains source and all task/settings data.

## Upgrade

Finish active work before changing the checkout. Existing manual/system service
processes must be stopped through their original launcher before using this manager.

```bash
git fetch origin tag v1.2.5
git switch --detach refs/tags/v1.2.5
./strixops.sh install
./strixops.sh start
./strixops.sh status
```

Keep the same data-path environment overrides and `--runs-root` when migrating
an existing deployment. No data migration, certificate reimport or image rebuild
is required for this release. Reload the browser after upgrading.

The manager is included in Git and source distributions; installed wheels continue
to use their normal Console entrypoint. See [management instructions](management.md)
for complete command behavior and preserved data.
