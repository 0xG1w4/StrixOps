# StrixOps v1.1.7

Release date: 2026-09-11.

Web and Internal tasks now have persistent notes shared by the root and child
Agents, with a read-only Notes tab in the Console. The five tool names follow
original Strix, while storage and lifecycle use StrixOps task-owned state.

## Changes

- Add `create_note`, `list_notes`, `get_note`, `update_note` and `delete_note`
  to the common Web/Internal tool set. Keep different tasks isolated.
- Persist successful changes atomically, check revisions before replacement or
  deletion, support atomic append, and retain bounded history and soft deletion.
- Return truthful nonfatal errors for validation, conflicts and unavailable
  storage. Preserve damaged files and leave task cancellation intact.
- Guide Agents to reuse relevant notes before recon or independent validation,
  and distinguish notes from verified findings and formal reports.
- Add paginated search, filters, detail and lazy history in the Notes tab, with
  visible refresh, old-run empty states and retryable read errors.

This release introduces no new external service or dependency. MCP tasks,
containers and certificates retain their separate existing flow. Notes share
information within one normal assessment task; they are not cross-task memory.
The Console view is read-only, and only Agent tools mutate notes in this phase.

See the [shared notes guide](shared-notes.md) for tool behavior, limits,
persistence, access and failure handling.

## Upgrade

```bash
git fetch origin tag v1.1.7
git switch --detach refs/tags/v1.1.7
npm --prefix console/web ci
npm --prefix console/web run build
uv sync --frozen --no-dev
```

Restart Console with its existing persistent paths after current work completes.
Start a new Web/Internal scan to use the updated tools and prompt bundle.
Older prompt snapshots remain unchanged and runs without notes display an empty
Notes tab. No data migration, sandbox image rebuild or CA reimport is required.
