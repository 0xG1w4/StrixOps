# StrixOps v1.1.9

Release date: 2026-09-11.

Web-search diagnostics now open from a compact button in the task header,
leaving more vertical space for the conversation and hint composer.

## Task page

- The header button shows task-wide call counts and recorded diagnostic alerts.
- Desktop uses a drawer over the right side of the page; phones use a
  full-screen panel. The conversation layout remains in place underneath.
- The panel retains success/failure/skip counts, actual API requests, timing,
  token usage, reported cost and recent call records.
- Closing the panel restores keyboard focus without resetting the selected
  Agent, conversation or hint draft.
- Unknown records and missing usage are not displayed as zero. Read failures
  retain prior records when available and allow retry.

The task still has five main tabs. The button and panel share one diagnostic
reader. Opening the panel does not call Perplexity or change search execution,
model routing, nonfatal error handling, containers or the separate MCP flow.
See the [task page guide](task-page.md) for operation details.

## Upgrade

```bash
git fetch origin tag v1.1.9
git switch --detach refs/tags/v1.1.9
npm --prefix console/web ci
npm --prefix console/web run build
uv sync --frozen --no-dev
```

Restart Console using the existing persistent paths after current work completes.
This release requires no task-data migration, sandbox image rebuild or
certificate reimport.
