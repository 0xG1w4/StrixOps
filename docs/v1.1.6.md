# StrixOps v1.1.6

Release date: 2026-09-11.

This release includes the additional Agent prompt edits and the new
`prompt_parts/environment.md` resource. The changes apply to new Web/Internal
root and child Agents; MCP request tests keep their separate prompt pipeline.

## Prompt behavior

- Start with bounded reconnaissance, then delegate specialists as surfaces are
  discovered. Check existing coverage and reports before assigning overlapping work.
- Give children explicit discovery or independent validation roles. Reserve
  available capacity for validation; if time or Agent limits prevent it, retain
  an unverified candidate and report the gap. These are prompt instructions,
  not a new engine-enforced validation gate.
- Prefer installed tools and relevant skills before writing custom code. Use
  bounded batches for repetitive tests when appropriate, preserve browser-based
  validation when interaction matters, and honor operator traffic constraints.
- Use neutral test values while retaining required attribution and evidence
  correlation. Do not remove operator-required headers or user-agents.
- Verify the sandbox identity and available tools. The bundled image defaults
  to root; custom images may differ. Keep findings and evidence under `/workspace`.
- Diagnose Caido-generated errors using the actual cause and captured evidence.
  A missing stored response does not establish that a target received nothing,
  and a TLS error does not always imply an incorrect HTTP/HTTPS scheme.

Independent validation can consume additional Agent calls and time. Existing
engine admission limits remain authoritative; the prompt now gives a completion
path when validation capacity is unavailable.

## Snapshot compatibility

Older run snapshots do not contain `environment.md`. The prompt renderer skips
that additional section for those snapshots instead of failing or silently
reading newer live content. Existing snapshot bytes and hashes are preserved.
New runs capture the environment resource with the other prompt files.

## Upgrade

```bash
git fetch origin tag v1.1.6
git switch --detach refs/tags/v1.1.6
npm --prefix console/web ci
npm --prefix console/web run build
uv sync --frozen --no-dev
```

Restart Console with its existing persistent paths after current work completes.
Start a new scan to use the updated prompt bundle. No data migration, sandbox
image rebuild or CA reimport is required.
