# Login observatory artwork and design

Introduced in StrixOps v1.3.4. The artwork is served locally with the Console;
all labels and controls are HTML and the account flow uses the existing APIs.

The layout keeps the centered landscape artwork on the left and form on the right.
A common StrixOps identity row ties them together. Warm highlights from the image
inform the brand and primary action; the credentials form a single visual group.
Narrow layouts stack while keeping the artwork horizontal. Short landscape phone
layouts use two columns so the fields are visible with less scrolling.
Reduced-motion settings disable the short entrance and control transitions.

## Artwork

New original artwork generated with the built-in imagegen tool on 2026-09-13.
Project asset: `console/web/public/images/login-observatory.webp`.
The 1672 × 941 generated image is encoded as WebP at quality 88 (276,346 bytes)
without resizing or visual editing. The existing release artwork is preserved.

Left and right edges gently fall into midnight blue while still carrying small stars. Premium observatory mood, balanced contrast with readable detailed shadows, soft restrained highlights without glaring white hotspots. No text, typography, branding, owl drawing, constellations drawn with lines, watermarks, UI, panel frames, charts, planets, sun, spacecraft, mountains, horizon or people.
