# StrixOps v1.1.10

Release date: 2026-09-12.

This release includes updated Agent guidance, an expanded skill library and
improved report formatting with basic Mermaid flowchart rendering.

## Prompts and skills

Root and child guidance emphasizes authorized security validation and
evidence-driven work. Six existing skills have expanded coverage: Kubernetes,
lateral movement, persistence/OPSEC, Linux privilege escalation, Windows
privilege escalation, and JWT authentication.

Six skills are added:

- `cloud/container_escape`
- `custom/api_attacks`
- `internal/relay_and_coercion`
- `reconnaissance/osint`
- `vulnerabilities/crypto_attacks`
- `vulnerabilities/tls_attacks`

The library now contains 92 discoverable skills. Default skill selection is
unchanged. Existing task prompt snapshots remain unchanged; new sessions use
the updated resources through the existing skill-loading and snapshot paths.
The MIT attribution and complete license for adapted claude-red content are
included in `NOTICE`; the separate reference repository is not a runtime
dependency.

## Reports

The synthesis prompt requests short paragraphs, meaningful subsections, GFM
tables and language-tagged code blocks. A simple flowchart may illustrate an
evidence-supported attack path or environment layout.

The Console loads Mermaid only when a supported diagram is present. The viewer
accepts bounded basic flowcharts with ordinary nodes and directed edges, then
rebuilds their source before rendering. Images, styling directives, click
actions and other unsupported syntax are displayed as the original code block.
Diagram failures also fall back to source, and ordinary Markdown remains
readable. Downloaded Markdown retains the original report text.
Wide diagrams scroll inside their frame to preserve readable labels on small
screens.

Search execution, model routing, task storage and container behavior are
unchanged. The separate MCP task flow is unchanged.

## Upgrade

```bash
git fetch origin tag v1.1.10
git switch --detach refs/tags/v1.1.10
npm --prefix console/web ci
npm --prefix console/web run build
uv sync --frozen --no-dev
```

Restart Console with its existing persistent paths after current work completes.
No task-data migration, sandbox image rebuild or certificate reimport is required.
