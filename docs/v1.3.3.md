# StrixOps v1.3.3

Release date: 2026-09-13.

The login starfield now uses a landscape 16:9 frame. Desktop layouts keep the
artwork on the left and the compact login form on the right, with refined brand
typography, spacing and button contrast. On narrow screens, the artwork and form
stack vertically while the image retains its landscape proportions.

The page continues to use the existing account and session flow. Saved passwords
and login sessions are retained; this release does not reset account data.

## Upgrade

Once outstanding work has completed, update the checkout and run:

```bash
./strixops.sh install
./strixops.sh start
./strixops.sh status
```

Reload the browser to load the new layout. The sandbox image remains
`strixops-sandbox:1.3.0`; no sandbox rebuild or proxy CA reimport is required.

See [account settings](authentication.md) and [artwork source](login-artwork.md).
